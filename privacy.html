Klipper API Trial

Kebijakan privasi

Terakhir diperbarui: 20 Oktober 2026.

Klipper API Trial dikelola Komedi Klip. Integrasi TikTok masih dalam pengembangan. Kebijakan ini menjelaskan penanganan data yang disiapkan untuk pengujian koneksi dan pengiriman video atas persetujuan pemilik akun.

Data dan tujuan penggunaannya

  • Identitas dasar akun digunakan untuk memeriksa tujuan pengiriman.
  • Access token dan refresh token digunakan untuk mengakses API sesuai izin pemilik.
  • Video yang dipilih dan metadata yang diperlukan digunakan untuk mengirim konten ke TikTok.
  • ID pengiriman, waktu, status, dan rincian kegagalan digunakan untuk memeriksa hasil dan mencegah pengiriman ganda.

Penyimpanan dan pengiriman

Aplikasi desktop dirancang menyimpan token secara lokal dengan Windows DPAPI CurrentUser. Token tidak boleh dimasukkan ke laporan, chat, repository, atau halaman publik. Website informasi ini tidak menerima password atau token.

Video hanya dikirim setelah pemilik menyetujui pengiriman. Data yang diterima TikTok ditangani menurut kebijakan TikTok. File dan catatan lokal tidak dijual atau digunakan untuk periklanan oleh proyek ini.

Retensi dan penghapusan

Penyimpanan lokal belum mempunyai penghapusan otomatis. Pemilik mengendalikan penyimpanan file dan catatan pada komputernya. Token yang dicabut atau tidak lagi diperlukan harus dihapus dari penyimpanan lokal. Rahasia tidak disertakan dalam catatan operasional.

Pemilik dapat mencabut akses aplikasi melalui pengaturan TikTok dan meminta panduan penghapusan data lokal melalui kontak di bawah. Menghapus data lokal tidak menghapus konten yang sudah diterima atau dipublikasikan di TikTok; konten tersebut dikelola melalui TikTok.
